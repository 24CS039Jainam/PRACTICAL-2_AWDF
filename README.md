# AWDF Practical 2 - React Portfolio

## Subject
Advanced Web Development Frameworks (ITUE301)

## Practical
Practical 2: State Management and Routing in React

## Implemented
- React Router v6
- BrowserRouter
- NavLink navigation
- Home, Projects and Contact routes
- 404 Not Found route
- useState for dark/light mode
- useState for skills visibility
- Controlled contact form
- Live character count
- Live form preview
- Responsive design

## Run

```bash
npm install
npm run dev
```

Then open the URL shown by Vite, normally:

http://localhost:5173

##Key Points

- BrowserRouter enables client-side routing.
- Routes contains Route definitions.
- Link/NavLink changes routes without a full page reload.
- useState stores reactive component state.
- A controlled input gets its value from state and updates state using onChange.
- The `*` route handles unknown URLs as a 404 page.
